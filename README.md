# Bengkel Padang Motor

Motorcycle workshop management system with CART machine learning prediction.

## Tech Stack
- Laravel 12, Blade, MySQL
- Python 3, Flask, scikit-learn
- Vite

## Features
- Service transaction management (CRUD)
- Role-Based Access Control (Kasir / Pemilik)
- CART ML model for next-service prediction
- Component lifecycle tracking (KBS)
- Financial reporting dashboard
